# ころとも（β版）

**止めるは、いつでも効く。** ころころ走る小さなロボット。家のラジコンを「小さなロボット」にして、ロボット産業でいちばん大事にされる**安全のしくみ**を、家で実証するためのアプリです。宇宙産業・ロボット産業の準備の最初の一歩（アイデアノート 2026/11/3 追記）。

β版のロボットは、画面の中の「まね」です。ESP32 用のプログラムの下書き（`firmware/`）も入っています。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # ロボットの画面：http://localhost:3700/
npm test
```

- **ロボットの画面**（テレビやパソコン）：`http://localhost:3700/`。つなぐ番号・ブラックボックス・まねの電池は、**このパソコンからだけ**操作できる
- **操縦のスマホ**：同じ Wi-Fi で `http://<このパソコンのアドレス>:3700/control.html`。ロボットの画面の6けたの番号を入れてつなぐ（1回だけ・2分まで）

## ともはねのゲームとして

いまは **ともはねのゲーム**として遊んでもらう（2026-11-03 決定）。

- ともはねの町の地図で、ガレージのとなりの「🤖 ころとも」→「ともはねでログイン」→ 操縦の画面へ
- 「⭐ ゲームスタート」：部屋の中の星を3つ集めたらゴール（3分まで）。ロボットの画面に星とタイムが出る。ウサギがゴールをお祝い
- ともはねに知らせるのは、**ゴールの回数と遊んだ回数だけ**（アカウント画面に出る）。自己ベストのタイムは ころとも の中だけ
- ログインしなくても遊べる（家族で、ローカル回線だけで使うとき）。そのときは記録は残らない
- 安全のしくみは、ゲームのときもそのまま（止めるはいつでも効く・合図が途切れたら止まる）

| 環境変数 | 中身 |
| --- | --- |
| `TOMOHANE_URL` | ともはねのアドレス（ふだんは `http://localhost:3000`） |
| `LINK_SECRET` | ともはね と同じ値にする合言葉。**本番では必ず設定する** |
| `KOROTOMO_DATA` | 遊んだ記録の置き場所（ふだんは `data/`。git に入らない） |
| `PORT` | ポート（ふだんは 3700） |

## 安全のしくみ

| しくみ | 中身 |
| --- | --- |
| **止めるは、いつでも効く** | 赤い「止める」はいつも画面の一番上。押した瞬間に送る（3回まで送り直す）。止めたら「解除」するまで動かない。解除しても速さ0から |
| **合図が途切れたら自分で止まる** | スマホは0.5秒ごとに「生きてるよ」の合図。**いま動かしているスマホ**の合図が1.5秒とどかなければ、ほかのスマホが元気でも止まる。画面を離れても止まる |
| **命令に署名** | すべての命令に HMAC-SHA256 の署名。番号が前より大きく、時刻が5秒以内のものだけ通す（使い回しを防ぐ）。スマホの http でも動くように、署名の計算は自前（`public/hmac.js`、Node の暗号と一致を確認ずみ） |
| **危ない命令は2人の同意** | 速さの上限（ふだん30）を上げるのは、**2台のスマホが30秒以内にそろったときだけ**。10分で元にもどる。下げるのは1人でよい。上限をこえた命令は、ロボットが切る |
| **ブラックボックス** | だれが・いつ・何を命じたか（受けとらなかった命令も）を、ハッシュの鎖で記録。書きかえると鎖が切れて分かる |
| **いつもの動きと比べる** | 命じた速さに対して実際にどれだけ出ているかを覚え、いつもより3割以上遅いと、ヤマネコが「電池か車輪を見てみよう」 |
